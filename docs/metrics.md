# 指标字典

本文档定义看板中所有指标的口径与计算方式，确保团队协作时理解一致。

## 用户相关

| 指标 | 定义 | 计算方式 |
|---|---|---|
| 用户总数 | 唯一用户数 | `COUNT(DISTINCT customer_unique_id)` |
| 新增用户 | 某段时间内首次购买的用户 | 按 `first_purchase` 落在区间内 |
| 活跃用户 | 某段时间内有购买行为的用户 | 按 `last_purchase` 落在区间内 |
| 复购用户 | 购买次数 ≥ 2 的用户 | `frequency >= 2` |
| 复购率 | 复购用户占用户总数比例 | `复购用户 / 用户总数` |

## 交易相关

| 指标 | 定义 | 计算方式 |
|---|---|---|
| 订单数 | 已完成订单数 | `COUNT(DISTINCT order_id)`，仅 `delivered` |
| 总消费金额 | 所有订单金额之和 | `SUM(order_total)` |
| 客单价 | 平均每单金额 | `SUM(order_total) / COUNT(order_id)` |
| 人均消费 | 平均每位用户消费额 | `SUM(order_total) / COUNT(DISTINCT customer_unique_id)` |
| 订单金额 | 单笔订单总金额 | `item_total + freight_total` |

## RFM 指标

| 指标 | 定义 | 计算方式 |
|---|---|---|
| R (Recency) | 最近一次购买距参考日期的天数 | `DATE_DIFF('day', last_purchase, ref_date)` |
| F (Frequency) | 用户购买订单数 | `COUNT(DISTINCT order_id)` |
| M (Monetary) | 用户消费总金额 | `SUM(order_total)` |
| R/F/M 分数 | 按 NTILE(5) 分档 | 1-5 分，5 最好 |
| 参考日期 | RFM 计算基准日 | 数据最晚购买时间 + 1 天 = 2018-08-30 |

## 用户画像标签

| 标签 | 定义 | 计算方式 |
|---|---|---|
| 偏好类目 | 用户购买次数最多的商品品类 | `ROW_NUMBER() OVER (PARTITION BY user ORDER BY count DESC)` |
| 活跃时段 | 用户最常下单的时间段 | 小时映射：凌晨 0-6 / 上午 6-12 / 下午 12-18 / 晚间 18-24 |
| 地域 | 用户最后一次下单的城市与州 | 按 `purchase_ts DESC` 取第一条 |

## 分群定义

| 分群 | R | F | M | 运营含义 |
|---|---|---|---|---|
| 重要价值客户 | 高 | 高 | 高 | 核心用户，重点维护 |
| 重要发展客户 | 高 | 中 | 中 | 有潜力，值得培养 |
| 重要保持客户 | 低 | 高 | 高 | 曾经高价值，需召回 |
| 新客/潜力客户 | 中 | 低 | 低 | 新用户，需引导首购/复购 |
| 流失客户 | 低 | 低 | 低 | 长期未购，召回成本高 |
| 一般价值客户 | 中 | 中 | 中 | 待观察，可批量运营 |

> 说明：R/F/M 的高低由 `NTILE(5)` 分数决定，≥4 视为高，≤2 视为低。

## 数据口径说明

1. **订单状态**：仅统计 `order_status = 'delivered'` 的订单
2. **用户标识**：使用 `customer_unique_id`（真实用户），而非 `customer_id`（订单级客户）
3. **时间范围**：2016-09 至 2018-08
4. **金额单位**：巴西雷亚尔（R$）
5. **参考日期**：固定为 2018-08-30，不使用当前日期
